Joinery

Read it. Try it. Build with it.

A modular building system for Unity 6. Your players snap walls, floors and roofs together by socket or on a grid. When a part won't fit, the preview turns red and says why. Blueprints, undo/redo, save/load, structural collapse, durability, building areas with rules, menus and touch controls, with full C# source.

Read the manual Try the Windows demo

Coming soon to the Unity Asset Store.

Try it before you buy

The outdoor demo, built for Windows 64-bit. Unzip and run JoineryDemo.exe.

Download for Windows (39 MB)

Controls: E build · left click place · R rotate · wheel change part · X destroy · T move · U upgrade · Q radial menu · Tab catalog · Z / Y undo / redo · F5 / F9 save / load · V top-down view. The build is not code-signed, so Windows SmartScreen may ask you to confirm.

What's in the package

Build

  • Socket snapping and grids
  • Live preview that explains every refusal
  • Blueprints: whole houses in one go

Manage

  • Undo/redo for every action
  • Save and load with a backup copy
  • Collapse, durability, repair, upgrades

Any genre

  • Survival bases and interiors
  • Building areas with rules
  • First person, top-down, touch

Requirements and what it doesn't do

  • Unity 6000.5 or newer, Input System package, uGUI.
  • The system works in URP and Built-in; the demo materials are URP.
  • No inventory or resources system (the manual shows how to hook up your own), no networking, no HDRP, no VR.
